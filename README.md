# ทันใจ AI Studio V12.3.0

โครงการเดียวสำหรับสร้างภาพ เนื้อหา เสียง สไลด์ แต่งวิดีโอ และสร้างวิดีโอด้วย AI

## โครงสร้างที่รวมแล้ว

- หน้าเว็บหลักอยู่ที่ `/`
- หน้า “สร้างวิดีโอ” เป็นโมดูล `#createVideo` ภายในเว็บหลัก ใช้ Login เมนู ฟอนต์ และ Responsive ชุดเดียวกัน
- URL เดิม `/create-video/` มีไว้ส่งผู้ใช้กลับเข้าโมดูลหลักอัตโนมัติ จึงไม่เกิดเว็บย่อยอีกชุด
- ระบบสร้างวิดีโอฝั่งเซิร์ฟเวอร์อยู่ใน `server.mjs`
- GitHub Pages แสดงหน้าเว็บทั้งหมดจาก repository นี้
- โมดูลสร้างวิดีโอบน GitHub Pages เรียกบริการ Render ที่อยู่เบื้องหลัง

## งานปรับปรุง V12.3.0

- รวมแนวทางภาพจากชุด Stitch เข้ากับระบบจริง โดยไม่ยกหน้าต้นแบบมาทับฟังก์ชันเดิม
- ใช้ Design System เดียวทั้งสี ฟอนต์ เมนู Topbar การ์ด ปุ่ม ช่องกรอก และสถานะ Focus
- ลดความแน่นของ Dashboard และจัดลำดับสายตาใหม่
- ปรับ Desktop, Tablet และ Mobile โดยคง Sidebar แบบ Drawer บนอุปกรณ์ขนาดเล็ก
- ไม่เพิ่มเครดิต ชื่อโมเดล หรือความสามารถจำลองที่ Backend ยังไม่รองรับ
- รองรับผู้ใช้ที่ยังไม่พร้อมสร้างวิดีโอผ่าน API ด้วยเส้นทาง Prompt และการส่งคลิปกลับมาแต่งต่อ

## อัปโหลดขึ้น GitHub

1. เปิด repository `tanjai-ai-studio`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้ทับไฟล์เดิม
3. ห้ามอัปโหลด `.env` หรือ API Key
4. เปิด GitHub Pages จาก branch หลักและโฟลเดอร์ราก
5. เชื่อม Render service เดิมให้ใช้ repository `tanjai-ai-studio`
6. ตั้ง `OPENAI_API_KEY` ใน Environment ของ Render เท่านั้น และตั้ง `GEMINI_API_KEY` เพิ่มได้หากต้องการใช้ Gemini ช่วยวาง Storyboard
7. Deploy แล้วตรวจ `/api/health`

## ทดสอบในเครื่อง

```bash
npm test
npm start
```

เปิด `http://localhost:4173/` สำหรับหน้าเว็บหลัก และ `http://localhost:4173/#createVideo` สำหรับโมดูลสร้างวิดีโอ

## ข้อจำกัดที่ต้องรู้

- GitHub Pages ไม่สามารถประมวลผลวิดีโอเองได้ จึงยังต้องมี Render เป็นบริการเบื้องหลัง
- การสร้างวิดีโอภายในเว็บต้องมีเครดิต API และ `ffmpeg` ในบริการ Render; หากเครดิตไม่พร้อม ผู้ใช้ยังคัดลอก Prompt ไปสร้างต่อและนำคลิปกลับมาแต่งได้
- ห้ามสร้างหรือดัดแปลงใบหน้าบุคคลจริง ระบบใช้ภาพกิจกรรม สถานที่ วัตถุ หรือภาพกว้างแทน
