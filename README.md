- มีปุ่มให้ AI เขียนแคปชั่นใหม่ และการขยับปกจะไม่เขียนทับแคปชั่นที่ผู้ใช้แก้แล้ว

- ใช้ข้อมูลจริงชุดเดียวกับภาพปก พรีวิว Facebook แคปชั่น และไฟล์ดาวน์โหลด
- รายละเอียด “ใครทำอะไร” ย่อขนาดอัตโนมัติและแสดงครบ ไม่ใส่ข้อความตัวอย่างลงในภาพจริง
- ค่าเริ่มต้นเป็นกลาง ไม่ผูกกับเทศบาลหรือองค์กรใด เพื่อรองรับการนำไปใช้ต่อ

## Context Intelligence & AI Fallback V12.6.3

- กรอกข้อมูลครั้งเดียวแล้วเลือกนำหัวข้อ หน่วยงาน กลุ่มเป้าหมาย โทน รายละเอียด วันเวลา สถานที่ และบุคคลไปใช้ต่อได้
- ข้อมูลในงานปัจจุบันมีสิทธิ์เหนือบริบทเดิม และผู้ใช้เลือกปิดบริบทแยกแต่ละเมนูได้ ป้องกันข้อมูลคนละโครงการปะปน
- งานเขียนและการอ่านไฟล์ใช้ Gemini เป็นระบบหลัก และสลับไป OpenRouter อัตโนมัติเมื่อระบบหลักไม่พร้อม
- รองรับระบบสำรองสำหรับข้อความ รูปเอกสาร PDF ข้อความ CSV และเสียง โดยไม่แสดงชื่อผู้ให้บริการหรือข้อผิดพลาดหลังบ้านแก่ผู้ใช้
- เมนูสร้างภาพและแต่งภาพ AI คงพฤติกรรมเดิมทั้งหมด

### ตั้งค่า Worker เพิ่มเติม

ตั้ง Secret `OPENROUTER_API_KEY` ใน Cloudflare Worker และ deploy โฟลเดอร์ `ai-worker` อีกครั้ง ระบบจะใช้ `openrouter/auto` เป็นค่าเริ่มต้น หรือกำหนด `OPENROUTER_MODEL` และ `OPENROUTER_FILE_MODEL` เองได้

- เพิ่มเครื่องมือปรับงานต่อ: กระชับขึ้น ทางการขึ้น เป็นธรรมชาติขึ้น เขียนหัวเปิดใหม่ และตรวจภาษา

## อัปโหลดขึ้น GitHub

1. เปิด repository `tanjai-ai-studio`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดใน ZIP นี้ทับไฟล์เดิม
3. ห้ามอัปโหลด `.env` หรือ API Key
4. เปิด GitHub Pages จาก branch หลักและโฟลเดอร์ราก
5. เชื่อม Render service เดิมให้ใช้ repository `tanjai-ai-studio`
6. ตั้ง `OPENAI_API_KEY` ใน Environment ของ Render เท่านั้น และตั้ง `GEMINI_API_KEY` เพิ่มได้หากต้องการใช้ Gemini ช่วยวาง Storyboard
7. Deploy แล้วตรวจ `/api/health`

## ข้อจำกัดที่ต้องรู้

- GitHub Pages ไม่สามารถประมวลผลวิดีโอเองได้ จึงยังต้องมี Render เป็นบริการเบื้องหลัง
- การสร้างวิดีโอภายในเว็บต้องมีเครดิต API และ `ffmpeg` ในบริการ Render; หากเครดิตไม่พร้อม ผู้ใช้ยังคัดลอก Prompt ไปสร้างต่อและนำคลิปกลับมาแต่งได้
- ห้ามสร้างหรือดัดแปลงใบหน้าบุคคลจริง ระบบใช้ภาพกิจกรรม สถานที่ วัตถุ หรือภาพกว้างแทน
